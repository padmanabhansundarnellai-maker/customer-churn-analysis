# Customer Churn Analysis

**Problem:** Analyze customer churn patterns and identify factors associated with customer loss.

**Dataset:** Telco Customer Churn dataset, 7,043 customers.

**What I did:**

* Cleaned customer data using Python and Pandas
* Handled missing values and converted data types
* Analyzed churn by tenure and contract type
* Wrote SQL queries in MySQL for churn analysis

**Key Findings:**

* Customers: 7,043
* Overall churn rate: 26.5%
* 0–12 month tenure churn: 47.4%
* Month-to-month contract churn: 42.7%
* Two-year contract churn: 2.8%
